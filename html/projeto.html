Projeto do site

Conheça os objetivos, tecnologias utilizadas, dificuldades encontradas e principais características do desenvolvimento do site MRG Motors.

Objetivos

O objetivo do site MRG Motors é apresentar e vender os produtos de uma concessionária fictícia especializada em carros premium e supercarros. Oferecendo aos clientes todas as informações necessárias sobre os veículos disponíveis.

Público-alvo

O site é voltado para pessoas interessadas em carros esportivos, veículos de luxo e modelos exclusivos. Também busca atender clientes que desejam consultar informações de forma rápida, clara e organizada antes de entrar em contato com a concessionária.

Tecnologias utilizadas

O projeto foi desenvolvido utilizando HTML5 para a estrutura das páginas e CSS para a estilização, organização visual e responsividade.

Requisitos mínimos para o usuário

Para acessar o site, o usuário precisa de um navegador atualizado, como Google Chrome, Mozilla Firefox, Microsoft Edge ou Safari. Também é necessária conexão com a internet para carregar imagens, fontes externas, mapa incorporado e links de notícias externas.

Dificuldades encontradas

As principais dificuldades encontradas foram a adaptação do layout para diferentes tamanhos de tela, o ajuste da qualidade das imagens e o processo de criação da identidade visual do site.

Pontos fortes

Entre os pontos fortes do projeto estão a identidade visual consistente, o uso de cores contrastantes, a navegação simples, a organização das páginas por tema, os cards de veículos, as páginas individuais com detalhes completos e a responsividade aplicada em todas as páginas.

Pontos fracos

O site ainda possui formulários simples em HTML, sem integração real com banco de dados ou sistema de autenticação. Além disso, por se tratar de um projeto acadêmico, os veículos, preços e dados comerciais apresentados são fictícios ou retirados de concessionárias reais.

Periodicidade de atualização

No caso de uma apliação real do site em uma concessionária verdadeira, o site seria atualizado semanalmente para a adição de novas notícias e sempre que houvese inclusão de novos veículos no estoque, atualização de preços, remoção de modelos vendidos, revisão das condições de pagamento e publicação de novas notícias relacionadas ao mercado automotivo.

Uso de Bootstrap

O Bootstrap não foi utilizado para este projeto. Toda a estilização foi feita com CSS autoral dos integrantes do grupo, buscando manter uma identidade visual própria e única.
